## Upload using GitHub in your browser
1. Extract this ZIP on your Mac.
2. Open https://github.com/sobellybutton/meowbox/tree/main/assets/visual/staging
3. Select Add file > Upload files. In Finder open the extracted assets/visual/staging folder.
4. Select all 11 folders inside staging, and drag them into the GitHub upload area together. Do not drag the outer assets folder or the ZIP. Keep all subfolders intact.
5. Confirm the queued paths begin with the dated folder names below, not assets/visual/staging again. Commit the upload to main if allowed; otherwise create a branch and pull request. Optional commit message: Stage Pawradise creative batches 01–05 and earlier motion assets.
6. Tell ChatGPT "uploaded, continue". If GitHub rejects an upload or reports conflicts, stop and report the message. Do not overwrite live art.
