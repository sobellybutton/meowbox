## Handoff rule

For each newly identified creative blocker, report the existing task ID, exact asset path or missing slot, evidence (including screenshot/frame/viewport when available), defect, replace/repair/reuse decision, and a concise creation brief specifying native composition, layers, anchors, transparency, and intended scene. Do not treat concept boards as game backgrounds or request new art to fix a runtime geometry issue. Continue independent work while blocked; preserve active leases and never promote a task purely because an asset was generated. Import to intended paths, verify hashes and image decode, integrate, then play and inspect real rendered experience. Actual phone and desktop release gates remain mandatory. Update this handoff as findings change, without duplicating task counts.
